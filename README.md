## Análisis de seguridad

Este repositorio se analiza con [SegFix](https://platform.segfix.io): escaneo de dependencias y
código, remediación asistida por IA y Pull Request con las correcciones. La política que se le
aplica (qué frena un despliegue, qué se puede exceptuar) la define el **perfil de seguridad**
asignado al proyecto *Canales Digitales*.
